# Changelog

Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [SemVer](https://semver.org/).

## [1.0.0] - 2026-11-21

### Added

- `DynamicGridLayoutGroup`: drop-in replacement for `GridLayoutGroup`.
- `GridLayoutCell`: cells spanning several slots along the *Start Axis*.
- `Partial Line Alignment` for lines that aren't full.
- `Adaptive Constraint` (columns/rows within `Min Count`–`Max Count`).
- `Cell Size Mode`: `Preserve`, `Stretch` and `FitContent` (variable sizes).
- *Convert to Dynamic Grid Layout Group* context menu.
- `Demo` sample.
- Full guide in `Documentation~` and README with example screenshots.
